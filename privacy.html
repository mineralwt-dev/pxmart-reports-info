資料使用與隱私權政策

適用程式：PXMart Reports Background。此程式由帳戶持有人自行建立，僅供其工作使用。

存取哪些 Google 資料

程式透過 Google Drive API 讀取帳戶持有人原有的庫存歷史 CSV，並建立及驗證產生的 CSV 與 Excel 報表。背景流程的程式設定限制在原本指定的報表與歷史資料資料夾，不變更檔案的分享設定。

Google 授權包含 drive.readonly 與 drive.file。前者在 Google 帳戶層級允許讀取持有人可存取的 Drive 檔案；本程式另外以資料夾允許清單限制實際讀取。後者允許管理本程式建立或經持有人允許的檔案；本程式用它建立、檢查及完成報表上傳，不覆寫內容不同的既有檔案。

用途與分享

上述資料只用於產生持有人指定的業務報表、同步檔案及檢查同步結果。背景產生及同步流程不呼叫生成式 AI 模型，不將資料出售、用於廣告或建立其他人的使用者檔案，也不向其他使用者公開資料。Google 會依其服務條款處理傳送到 Google Drive 的檔案及 API 請求。

本程式使用及傳送從 Google API 取得的資料，遵循 Google API Services User Data Policy，包括 Limited Use 要求。帳戶持有人另行指示的人工檢查或其他服務中的分析，適用該項工作的授權與服務政策。

儲存與保護

正式雲端檔案保留在持有人原有的 Google Drive 位置。本機背景工作區保留產生報表所需的歷史檔、產物及狀態紀錄。Google 更新權杖以 Windows 專用服務身分的 CurrentUser DPAPI 加密，憑證及工作資料目錄使用 Windows 存取權限隔離；一般桌面帳戶不具有該憑證儲存區的讀取權限。Windows 系統管理員仍能提權接管電腦。

一般狀態紀錄只保留執行狀態、檔名、檔案識別碼、大小及校驗結果，不記錄密碼、授權碼或權杖。背景流程不接收或儲存持有人的 Google 登入密碼。私人除錯紀錄與工作產物也置於受保護工作區。

保留、撤銷與刪除

報表、歷史檔及本機工作資料保留到持有人依原有保存規則或管理作業刪除；本工具目前不承諾固定天數後自動刪除。持有人可在 Google 帳戶的第三方連線設定撤銷本程式存取權，並由電腦管理員停用背景服務及移除其憑證。撤銷授權本身不會刪除原有報表；雲端檔案可由持有人在 Drive 中管理或刪除。

聯絡與變更

如需查詢、停用或刪除本工具的資料，請聯絡帳戶持有人，或使用 Google 授權畫面所列的支援電子郵件。資料用途或授權範圍變更時，應先更新本說明；新增 Google 權限須由持有人再次同意。
